# How-to — Notes & export

**Objectif** : écrire une note, l’archiver, exporter des données projet / tâches.

## Notes

1. **Notes** → nouvelle note (ou base de données).
2. Sync en ligne ; brouillon local si hors ligne.
3. Archives : notes retirées, restaurables.

## Export

| Quoi | Où |
|------|-----|
| Tâches CSV | Mes tâches / outils d’export |
| Projet | Menu projet → export |
| Compte (RGPD) | Paramètres → données / export |

Cold path données : [cold-path-donnees.md](../cold-path-donnees.md).
