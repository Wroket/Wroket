# How-to — Tâches & assignations

**Objectif** : créer une tâche, la planifier, l’assigner à un collaborateur.

## Créer

1. **Mes tâches** → Nouvelle tâche (titre + priorité).
2. Optionnel : projet / phase, échéance, tags.
3. Pour planifier tout de suite : **Planifier** → choisir un créneau (ou Agenda `?schedule=`).

Parcours guidé : [cold-path-first-slot.md](../cold-path-first-slot.md).

## Assigner

1. Ouvrir la tâche → champ **Assigné à** → membre d’équipe.
2. L’assigné reçoit une notif (accepter / refuser).
3. Statuts : pending → accepted / declined (badge hors modal).

Prérequis : plan avec équipes / collaborateurs. Voir [cold-path-collab.md](../cold-path-collab.md).

## Astuces

- **Assist** → « Planifie ma semaine » propose des créneaux (confirm avant réservation).
- Contrainte phase / dates / créneau : l’app propose des **choix**, pas un toast seul.
