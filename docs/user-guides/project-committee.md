# How-to — Projet & comité

**Objectif** : piloter un projet et préparer un comité (santé, retards, lien partage).

## Projet

1. **Projets** → créer / ouvrir un projet.
2. Vues **Board / Kanban / Gantt** : un déplacement aligne les vues.
3. Onglet **Pilotage** : santé, charge, retards.

Checklist : [cold-path-projects.md](../cold-path-projects.md).

## Assist — Prépare mon comité

1. Dashboard (**Assist**) ou Pilotage projet → **Prépare mon comité**.
2. Preview : santé, retards, bloqueurs, liens share actifs.
3. Confirmer pour créer un **lien lecture seule 7 jours** (si droits d’édition).

Détail technique : [assist-pmo-commands.md](../assist-pmo-commands.md).

## Partage

- Menu projet → partage lecture seule (onglets pilotage / kanban / gantt).
- Révoquer un lien dès qu’il n’est plus utile (Paramètres projet / liste des liens).
